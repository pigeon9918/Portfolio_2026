## 1. 시스템 개요
본 프로젝트는 STM32 F401 MCU와 TFT-LCD, XPT2046 터치 컨트롤러를 활용하여 사용자 친화적인 그래픽 터치 인터페이스를 구현한 시스템입니다.

double line buffering과 DMA를 활용하여 그래픽 렌더링 - SPI 전송 과정 파이프라인을 구현하고 병렬성을 끌어올리는 것을 목표로 합니다. 

### 1.1. 핵심 기능
- **그래픽 터치 인터페이스:**
  - **클릭 및 드래그:** 마우스 커서 이동 및 버튼 조작 지원.
  - **마우스 커서:** 현재 위치를 실시간으로 표시하여 사용자 피드백 강화.
  - **기능 버튼:** 터치 UI를 통해 배경 색상 전환, LED 토글 등 특정 동작 수행.
- **실시간 배경 및 아이콘 렌더링:**
  - 배경과 아이콘을 실시간으로 렌더링하며, 아이콘의 위치 변화를 즉각적으로 화면에 반영.

## 2. 터치 구현 상세
### 2.1. XPT2046 데이터 시트 분석
- **통신 방식:** 양방향 SPI 통신 (최대 2.5MHz).
- **출력:** X, Y, Z축 12-bit 데이터.
- **동작 모드:** 12-bit, Interrupt Enabled, Differential 모드를 기본으로 사용하며, 좌표 수신을 위해 `0x90`(X), `0xD0`(Y) 커맨드 활용.

### 2.2. 인터럽트 vs 폴링 전략
터치 드래그 동작의 연속성을 확보하기 위해 **IRQ 핀을 활용한 폴링 방식**을 채택하였습니다.
- IRQ 핀이 터치 시 LOW로 떨어지는 특징을 Polling 조건에 추가하여 불필요한 부하를 방지.
- C언어의 **Short-circuit evaluation** 특징을 활용하여, 터치가 발생하지 않았을 때는 시간이 오래 걸리는 SPI 읽기 함수를 실행하지 않도록 최적화.

### 2.3. 노이즈 억제 및 안정화
- **Median Filter:** 5회의 SPI 전송 값 중 중간값을 취하는 **6-Comparison Median 알고리즘**을 적용하여 연산 비용 절감 및 ADC 노이즈 제거.
- **Hysteresis 및 임계값 설정:** 최근 커서 위치와 비교하여 5픽셀 이상 변화가 있을 때만 업데이트하도록 설계하여 미세한 커서 떨림 현상을 억제.

## 3. 소프트웨어 특징
### 3.1. Non-blocking 구조
- `HAL_Delay` 대신 시스템 `tick`을 활용한 Non-blocking 구조를 적용하여 시스템 전체가 멈추지 않고 여러 작업을 concurrent하게 처리.

### 3.2. 실시간 화면 렌더링 엔진
- **배경 렌더링:** 배경을 지정된 이미지가 아닌, 프레임별 변하는 변수를 이용하여 움직이는 배경 화면을 구현.
- **엔티티 기반 렌더링:** 배경 위에 아이콘 엔티티를 덮어씌우는 방식을 통해 마우스 커서와 버튼 UI를 효율적으로 구현.
- **Frame Rate 제어:** Tick 기반 2ms 제한을 통해 최대 프레임을 관리하고, non-blocking 구조를 이용하여 프레임 드롭 최소화.

## 4. 활용 가능성 및 확장성
- **GUI 애플리케이션:** 스마트 홈 기기, 의료 장비, 3D 프린터 제어 인터페이스 등 소형 디스플레이 시스템의 UI로 활용 가능.
- **레트로 게임기:** 현재 렌더링 엔진에 물리 엔진을 결합하여 터치스크린 기반의 2D 플랫폼 게임 제작 가능.
