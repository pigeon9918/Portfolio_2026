# [Among USEE] 코로나19 출입 명부 기록 시스템

### 발표자료
- **시연동영상:** [Youtube](https://youtube.com/shorts/olo6WOHEbCA?si=NBAUP94LFthbNN7f)
- **포스터**: [PDF](./Among_USEE.pdf)

---

### 1. 간단한 작품 설명
**"지문 하나로 끝내는 스마트 안심 출입 명부"**
코로나19 상황에서 수기 명부 작성이 번거로움과 개인정보 노출 문제를 해결하기 위해 고안되었습니다. 친숙한 'Among Us' 캐릭터 디자인의 하우징 속에 지문 인식과 비접촉 온도 측정 기능을 결합하여, 빠르고 안전하게 출입 기록을 관리하는 IoT 시스템입니다.

---

### 2. 구성 그림 & 사진
- **HW 구성:** 
  - **Main:** Arduino 기반 제어기
  - **Sensors:** 지문 인식 센서, 비접촉 온도 센서, character LCD 스크린
  - **UI/UX:** 입력용 버튼, 상태 알림용 부저 및 LED
- **3D 모델링:** 'Among Us' 캐릭터 형태의 케이스
- **Software:** 데이터베이스 연동 웹사이트 (명부 확인용)

---

### 3. 프로젝트 상세 설명

**[시스템 핵심 프로세스]**
1. **사용자 등록:** 기기 전면의 버튼을 이용해 학번을 입력한 후, 자신의 지문을 시스템에 최초 등록합니다.
2. **출입 인증:** 회실 입장 시 등록한 지문을 센서에 스캔합니다.
3. **인증 성공 (Crewmate):** 
   - 스크린에 **'학번, 체온'** 이 실시간으로 출력됩니다.
   - 정상 출입 데이터가 서버로 전송되어 데이터베이스에 기록됩니다.
4. **인증 실패 (Imposter):**
   - 등록되지 않은 지문일 경우 스크린에 **'Imposter'** 문구가 표시되며 경고 알람이 발생합니다.
5. **웹 모니터링:** 관리자는 전용 웹사이트를 통해 실시간으로 누적된 출입 명부를 안전하게 확인하고 관리할 수 있습니다.
