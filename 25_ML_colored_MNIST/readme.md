## 1. 프로젝트 핵심 요약
- **하이브리드 접근법**: 색상 분류는 **확정적 알고리즘(Palette-Area)**으로, 숫자 분류는 **머신러닝(OvO-SVC)**으로 해결하여 성능과 효율을 모두 잡았습니다.
- **CUDA 가속 및 VRAM 관리**: 프로젝트의 빠른 진행을 위해 `cuML`을 도입, 압도적인 학습 속도를 확보하고 한정된 VRAM 자원을 효율적으로 관리하여 대규모 그리드 탐색을 수행했습니다.
- **도메인 지식 기반 전처리**: 숫자 인식의 핵심인 '형태'에 집중하기 위해 흑백 변환 및 배경색 통제(Black Background) 전처리를 도입하여 모델의 편향을 제거했습니다.
- **최종 성능**: 
  - **숫자 분류 정확도: 98.82%**
  - **전경/배경색 분류 정확도: 100.00%**

## 2. 주요 방법론

### 2.1. 색상 분류: 알고리즘적 접근 (100% Accuracy)
- **문제 인식**: SVC 등 ML 모델이 전경색 분류에서 100%를 달성하지 못하는 한계 발견 (t-SNE 분석 결과 전경색의 명확성 부족 확인).
- **솔루션**: 데이터 생성 규칙(팔레트)을 역이용하여 픽셀 빈도수를 계산.
- **결과**: 면적이 넓은 쪽을 배경으로, 좁은 쪽을 전경으로 정의하는 **팔레트 매칭 알고리즘**을 통해 연산량은 줄이면서 정확도 100%를 달성했습니다.
* **접근법**: 머신러닝 모델의 맹목적 적용보다, 문제의 본질을 분석하여 최적의 도구(알고리즘 vs ML)를 선택하는 의사결정을 중요시했습니다.


### 2.2. 숫자 분류: OvO-SVC 및 전처리
- **흑백 변환(BW)**: 색상 정보는 숫자 분류에 무관한 노이즈로 작용하므로, 이를 제거하고 형태적 특징에만 집중하도록 설계.
- **배경색 최적화**: 선형 모델이 배경의 높은 픽셀값(255)에 편향되는 문제를 해결하기 위해 배경을 검은색(0)으로 고정하는 전처리를 수행했습니다.
- **OvO(One-vs-One) 전략**: 클래스 간 경계가 복잡한 손글씨 데이터를 미세하게 분리하기 위해 45개의 이진 분류기를 학습시키는 OvO SVC를 최종 모델로 선정했습니다.

### 2.3. 데이터 증강 (Weakness Reinforcement)
혼동 행렬(Confusion Matrix) 분석을 통해 취약한 숫자 쌍(4-9, 3-8, 7-9)을 식별하고 집중 보완했습니다.
- **폰트 증강**: MaruBuri 폰트를 활용해 문자의 구조적 본질 학습 유도.
- **회전(Tilt) 증강**: 사람이 글씨를 쓸 때 발생하는 자연스러운 기울기(±5도)를 반영하여 일반화 성능 강화.

---

## 3. 하이퍼파라미터 조정 (Grid Search)
`cuML`의 병렬 연산을 활용하여 2단계 그리드 탐색을 수행했습니다.
- **1차 탐색**: 지수 스케일로 넓은 범위 탐색 (C=10, $\gamma$='scale' 유망 확인).
- **2차 탐색**: **5-Fold Cross Validation**을 도입하여 세밀한 튜닝 및 과적합 방지.
- **최종 파라미터**: `C=6`, `gamma=3e-07`
