## 1. 시스템 개요
이번 프로젝트는 ATtiny4313을 기반으로 한 **조명 제어 시스템**입니다. 로터리 엔코더와 PS/2 키보드를 통해 입력을 받고, OLED 디스플레이, 부저, PWM LED를 통해 시각 및 청각적 피드백을 제공합니다. 또한 UART 통신을 이용한 관리자 콘솔을 통해 시스템 상태를 실시간으로 모니터링할 수 있습니다.

프로젝트는 register를 직접 제어하는 코드를 작성하여 다양한 peripheral과 interrupt를 활용하면서도 최대한 HW 자원을 절약하는 것을 목표로 하고 있습니다.

### 1.1. 핵심 기능
- **상태 관리:** 사용자 입력에 따른 설정값 및 시스템 시간(`sys_tick`) 관리.
- **디스플레이 업데이트:** `counter` 값에 따라 OLED 게이지 UI를 50ms 주기로 실시간 갱신.
- **부저 피드백:** 키보드 입력 시 특정 음계(Scale) 재생.
- **PWM 제어:** 엔코더 또는 키보드 입력을 통해 LED 밝기 조절 (0~100%).
- **관리자 콘솔:** UART를 통해 시스템 내부 상태(Tick, Counter, Duty) 확인.

### 1.2. 입력 장치
- **Rotary Encoder**
  - **회전:** `counter` 값을 증감시켜 OLED 게이지 조절.
  - **스위치 클릭:** 현재 값을 PWM 출력(밝기)으로 확정.
  - **Timeout:** 3초간 입력이 없으면 조작 전 상태로 복귀.
- **PS/2 Keyboard**
  - **숫자 키('0'~'9'):** 해당 비율로 즉시 설정 및 대응하는 음계(Tone) 재생.

### 1.3. 출력 장치
- **OLED Display (SH1106):** 게이지 바 및 전구 아이콘 등 GUI 표시.
- **Buzzer:** 입력 피드백 음계 재생 및 자동 꺼짐 제어.
- **PWM Output (LED):** 설정값에 따른 밝기 변화 시뮬레이션.
- **Status LED:** 5초 간격 점멸을 통한 시스템 정상 동작(Heartbeat) 확인.
- **UART Console:** `ls` 명령어 입력 시 시스템 정보 출력.

## 3. 자원 활용 전략
### 3.1. 핀 절약 가능성 분석
- **입력 장치:** 사람의 조작은 불규칙하므로 안정성을 위해 입출력 핀 공유를 지양함.
- **HW 예약 기능:** USI SPI, Timer/PWM, UART 등은 전용 핀 사용이 필수적이어서 공유가 제한됨.

### 3.2. HW 자원의 효과적인 운용 (Timer0 공유)
- **Fast PWM Mode:** Timer0를 사용하여 LED PWM과 Buzzer Tone을 동시에 처리하면서, Timer Overflow Interrupt를 통해 시스템 `tick`을 생성.
- **Non-blocking Delay:** 단일 타이머로 PWM 출력과 시간 기반 제어 시스템을 동시 구현.

---

## 4. 소프트웨어 특징
### 4.1. Non-blocking 구조
- `delay_ms` 대신 `sys_tick`을 활용하여 시스템 멈춤 방지.
- `MS_TO_TICKS(m)` 매크로를 사용하여 시간 정확도 확보.
- 모든 작업은 "실행 시점"을 체크하여 concurrent하게 동작.

### 4.2. 인터럽트 기반 Input
- Polling 방식 대신 인터럽트를 사용하여 입력 감지.
- OLED 갱신 등 느린 동작 중에도 사용자 입력에 즉각 반응하여 시스템 효율성 극대화.
